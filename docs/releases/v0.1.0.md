# Stutter v0.1.0

First validated release. Every claim below is backed by the Core Validation campaign `core-c8b22a8-1792799432599`; the release candidate is commit `75d2f99d1e2f8c0bab50b747db33ead0061cb165`.

## Supported

`doctor`, `record`, `bench`, `report`, `audit`, `completions_and_man`.

## Experimental (not Supported)

- Diagnosis and the advisor. In the v0.1 calibration corpus all four diagnosis families (scheduler, I/O, IRQ, GPU) had 0.0 recall at the current thresholds.
- StutterScore and `tune_evaluation`. The score was non-monotonic in both the controlled runnable-latency experiment and the frame-time experiment.
- Every mutating capability (CPU affinity, priority and placement, system-wide tuning, always-on autotune, remote agent mutation, `restore`).

## Kernel evidence

Observed on Linux 6.12.112 (incompatible), 6.18.55 (degraded) and 7.2.9 (degraded). These are real observations, not a blanket compatibility claim.

## Verification

The package was verified with `xtask release-verify --require-acceptance` against live acceptance bundles taken at the exact release commit (observation, game-runnable, affinity, recovery). Verify downloads with `sha256sum -c SHA256SUMS`.
