# PMU interval accounting and bounded readback

Status: **existing four-event readback observed; optional six-event readback FAILED**.
No new autonomous capability or objective is qualified. Production services were untouched.

Linux perf's reset ioctl clears event counts, but retains cumulative enabled/running times
([ABI reference](https://man7.org/linux/man-pages/man2/perf_event_open.2.html)). The previous sampler
therefore scaled fresh counts by a lifetime ratio. The sampler now leaves its group enabled and
subtracts consecutive group snapshots for counts and both times. Missing/malformed reads require
a fresh baseline. Regressed counters, impossible times, oversized reads and scaling overflow fail
closed. Sensor conversion recomputes multiplexing from timings, marks partial thread sets
Approximate, and refuses overflow instead of saturating a value into direct evidence.

The sampler API also has optional generic branch/branch-miss events with explicit unsupported-event
metadata and bounded FD/buffer accounting. Both runtime constructors leave these **disabled**.
No software fault/migration or architecture-specific bandwidth events have been added yet.

Deterministic verification: 14 perf-counter tests passed (one live test ignored), five PMU sensor
tests passed, and library/test Clippy passed with warnings denied. Coverage includes cumulative
versus interval scaling (correct value 100 versus the old 40), lost-read re-priming, resets, overflow,
malformed timing, six-event decoding, optional events missing rather than zero, legacy JSON, false
multiplexing flags and partial thread sets.

The opt-in live own-thread fixture first used a sub-millisecond fixed loop and failed with zero
counts. One bounded follow-up used three 50 ms work intervals for each of the existing and optional
sets. Results:

* Existing four-event set: all three intervals counted (enabled equals running), positive cycles
  and instructions, IPC 2.318–2.345. This is counter mechanism observation on a synthetic CPU loop,
  not workload benefit or an installed-service acceptance result.
* Optional six-event set: its first 50.390 ms interval reported only 6.659 us running and zero
  counters; the fixture failed and stopped. This does not prove the optional event group is
  schedulable on this host, even though opening it succeeded. The sensor yields Missing for this
  zero-denominator data. No further retries or changes to quality thresholds were made.

The optional group remains **EvidenceDeferred**, with schedulability/PMU constraints unresolved.
