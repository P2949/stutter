# OpenRC safety and supervision development slice

Status: **PARTIAL / G0**. This is not a product controller/root-worker service qualification.
No installed host service was changed. The production controller and worker retained PIDs 1985
and 1889. No Stutter mutation was attempted.

The bounded-service installer now renders fixed per-user OpenRC identities, distinct service
names and root-directory pidfiles. Configuration is preserved across installation and removal.
The controller defaults to observation using the existing lightweight preset. Independently,
the root worker constructs an Observe policy for `STUTTER_SERVICE_BACKEND=openrc`, after trusted
configuration overrides. Socket callers cannot broaden that policy. Rollback remains allowed;
unknown backend tags fail startup. Existing systemd units keep their established policy.

Both templates use `supervise-daemon`, bounded respawn and group-stop schedules. The worker has
NoNewPrivs and an IAB bounding mask permitting only the existing worker capabilities (CHOWN,
DAC_OVERRIDE, SYS_PTRACE, SYS_NICE). A kernel defining capabilities above 40 is refused pending
review. Libcap 2.77 parsed the exact mask and confirmed the four inheritable/ambient entries and
the other 37 blocked entries; this was a parser check, not privileged execution/readback.
The syntax follows the [libcap IAB format](https://man7.org/linux/man-pages/man7/cap_text_formats.7.html)
and the [OpenRC supervisor interface](https://manpages.debian.org/testing/openrc/openrc-run.8.en.html).

Verification in the pinned development environment:

* 21 service tests and three bounded-worker tests passed. The rendered OpenRC fixture checks
  shell syntax, fixed identity despite preloaded configuration, dependency order, private paths,
  start/stop hooks, propagated restore failures, repeated install and uninstall/config retention.
* Clippy on the library and tests passed with warnings denied.
* An opt-in pinned OpenRC 0.64.1 build ran a real **unprivileged dummy-process** supervisor test:
  start, SIGKILL/respawn, stop, restart, NoNewPrivs readback and exit of all recorded processes.
  This tests the supervisor, not Stutter recovery or root-worker confinement.

Reproduction (the package never installs or activates host init services):

```sh

nix develop --command python3 tests/openrc/supervisor.py --package STORE_PATH --out NEW_DIRECTORY
```
