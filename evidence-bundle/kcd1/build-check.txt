KCD1 curated evidence bundle validation procedure

A refreshed bundle is considered valid only when all of the following complete
successfully:

- cargo fmt --all -- --check
- cargo run -p xtask -- ci
- cargo run -p xtask -- fixture-check
- cargo run -p xtask -- dependency-hygiene
- (cd evidence-bundle && sha256sum -c MANIFEST.sha256)
- scripts/artifacts/build_case_study_report.sh
- verification of the raw case-study archive checksum
- verification of the raw archive contents-listing checksum

Raw archive:

- release tag: case-study-kcd1-2026
- archive: stutter-kcd1-case-study-raw.tar.zst
- checksum: stutter-kcd1-case-study-raw.tar.zst.sha256
- contents listing: stutter-kcd1-case-study-raw.contents.txt
- contents checksum: stutter-kcd1-case-study-raw.contents.txt.sha256

Methodology note:

The archived KCD1 A/B run was paired but not counterbalanced. The result should
therefore be treated as low-confidence non-validation evidence. A stronger
follow-up experiment should use a counterbalanced repeated A/B protocol before
treating a tuning result as strong evidence.
