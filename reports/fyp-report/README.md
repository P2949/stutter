# FYP Report

- `FYP_REPORT.md` is the final long-form FYP report source for submission or
  export.
- `FYP_REPORT_NOTES.md` is a planning/evidence checklist used to keep the
  report grounded in repo artifacts.

The KCD1 case-study source material lives in `reports/kcd1-case-study/`.

Keep the notes file in the repository as internal planning material. The
submitted report should be based on `FYP_REPORT.md`, not the notes file.
