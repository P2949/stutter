# KCD1 Launch Smoke Test Summary

This file replaces the original smoke-test transcript with a redacted summary.
The raw transcript contained full Steam/runtime process command lines and a
monitor serial number, neither of which is needed for the presentation archive.

## MangoHud Logging

- A MangoHud CSV was created for the smoke launch.
- File ownership and home-directory paths are redacted in committed artifacts.
- Formal run CSVs are archived under `reports/kcd1-case-study/mangohud/`.

## Display Context

- Session: Sway/Wayland.
- Active output during the smoke test: 1920x1080 at 100 Hz.
- Display make/model/serial and compositor-internal node IDs were omitted from
  this committed summary.

## Process-Tree Check

- After closing KCD1, the smoke check confirmed that the game/Gamescope/Proton
  process tree was no longer present.
- Steam client and webhelper support processes could remain running after the
  game closed; those were not used as measurement roots.
- The formal recordings re-detected the live Gamescope/KCD process-tree root
  before each run.

## Measurement Launch Shape

```text
Steam -> Gamescope 1920x1080@100Hz -> MangoHud logging -> GE-Proton10-34 -> KingdomCome.exe +exec user.cfg
```

The raw process-command transcript was intentionally not retained in the
