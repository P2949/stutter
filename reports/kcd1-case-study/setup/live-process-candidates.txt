# Redacted Candidate Process Summary

This file replaces the original live `/proc` process-command capture with a
supervisor-safe summary. The raw capture was useful during setup, but it exposed
long Steam/runtime command lines and machine-specific paths that are not needed
for reproducing the case-study method.

## Purpose

Identify the correct live process-tree root for the KCD1/Gamescope/Proton
workload before starting formal recordings.

## Relevant Candidate Roots

| Candidate | Role | Selection note |
| --- | --- | --- |
| `gamescope` | Gamescope root around the Proton game launch | Best measurement root because it contains Gamescope, Proton/Wine helpers, and the KCD1 game process. |
| `Main` | KCD1 game process | Useful for confirming game threads, but too narrow because it excludes Gamescope/runtime work. |
| `wineserver`, `winedevice.exe`, `steam.exe` | Proton/Wine support processes | Useful context, but not suitable as the top-level recording root. |
| Steam runtime helpers | Launch/container support | Excluded as top-level roots because they include unrelated client/runtime noise. |

## Launch Shape

```text
Steam -> Gamescope 1920x1080@100Hz -> MangoHud logging -> GE-Proton10-34 -> KingdomCome.exe +exec user.cfg
```

Personal home paths, Steam webhelper arguments, pressure-vessel internals, and
full environment strings were intentionally omitted from this committed
artifact. The matching tree-topology artifacts under `setup/tree-candidates/`
and `setup/baseline-*-tree-check.txt` preserve the process relationship evidence
without the raw command-line dump.
